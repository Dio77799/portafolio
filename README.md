# Portafolio de James Velásquez

Portafolio personal en HTML, CSS y JavaScript puro (sin frameworks), con interfaz de
escritorio estilo Windows y publicado en GitHub Pages.

Incluye proyectos de desarrollo e IA aplicada, laboratorios de ciberseguridad defensiva
con su documentación, cursos completados y minijuegos web.

## Estructura

```
index.html    página completa (estilos, contenido e interactividad)
sistemas/     capturas de proyectos
labs/         fotos y apuntes de los laboratorios
juegos/       minijuegos (Three.js, p5.js, JS)
imagenes/     foto de perfil
```

## Editar contenido

Proyectos, cursos, galería y laboratorios están en los arreglos `PROYECTOS`,
`CERTIFICADOS`, `GALERIA` y `LABS` al final de `index.html`.

## Ver en local

Abre `index.html` en el navegador.
